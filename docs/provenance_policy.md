# Provenance and evidence policy

Every event and relationship must be traceable to a source record.

Retain the dataset ID, source system, source record ID, input filename, source version/URL/license when provided, evidence ID/status, source time, ingestion time, and transform version. The run report also records input format/size, elapsed time, measured counts, and warning counts.

`observed` means directly represented in an input record; `synthetic` means generated by this project; `enriched` means added from a referenced enrichment source; `derived` means deterministically inferred from explicit source fields under a documented rule. Do not label an enrichment or synthetic event as observed.

Do not treat correlation as causation, ATT&CK technique context as proof of an attack, KEV membership as proof an asset was exploited, or a suspicious event as a confirmed incident. Keep source record and evidence IDs attached to every candidate graph relationship.

Raw input files are read-only and are not copied into generated output. Rejected-record output omits raw row contents to avoid accidental disclosure.
