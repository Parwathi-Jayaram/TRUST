# Dataset licensing and attribution

This project ships no third-party cybersecurity dataset. A dataset must not be downloaded, copied into the repository, or redistributed solely because a public URL exists.

Before using a source, record its exact dataset/version, official URL, access date, file name/format, license or provider terms, required attribution, permitted use, size, and known limitations. If the official page does not clearly grant the intended reuse, do not redistribute; ask the provider or choose a source with clear terms.

Current Phase 0 findings:

- LANL Unified Host and Network Dataset: the official page marks the dataset CC0 1.0; cite the associated paper in project reports.
- CIC datasets: CIC's FAQ requires citations for use/redistribution. Recheck the selected dataset page and attribution before publishing derived/source data.
- CTU-13: the official page requests citation but does not state a clear reuse license; obtain provider clarification before redistribution.
- UNSW-NB15: the page grants free academic research use; commercial use requires agreement with the authors.
- MITRE ATT&CK: MITRE permits research, development, and commercial use subject to reproducing the stated copyright designation and license.
- CISA KEV: the catalog is CC0 1.0; linked third-party sources retain their own terms.
- NVD: check current NIST/NVD and any upstream CVE data conditions before mirroring.
